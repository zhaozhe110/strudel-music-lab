# 研究脚本归档

这里保留历次编曲、音色实验、音频分析、自动转写和渲染研究的源码。它们用于解释作品怎样形成，**不是新机器的安装入口**。日常工作使用根目录 [README](../README.md) 中的 `scripts/` 工具。

目录名对应旧工作区的隐藏目录，移除了开头的点。例如 `pocket-calculator-v4/` 来自旧 `.pocket-calculator-v4/`。只收录选定的顶层脚本、模板与文字记录；完整分离音轨、下载包、Python 环境和模型缓存仍在原工作区，不在此仓库中。

个人路径已替换为 `<LEGACY_WORKSPACE>` 或 `<USER_HOME>`。相对文件布局、第三方依赖和历史浏览器上下文并未全部迁移，因此不要直接批量运行归档脚本。确需重做某个实验时：先读对应脚本和 [HANDOFF](../HANDOFF.md)，确定输入、环境与输出，再迁移到独立目录。新 Python 环境优先用 conda。

旧流程的验证结果放在 [evidence/](../evidence/)。早期吉他预览含近似 DSP；后期电子作品使用实际 Superdough 引擎。两者的区别见交接文档，不能把历史试听统一称为完整原引擎渲染。
