# Strudel 本地音乐编辑器

## 日常使用

1. 双击本目录的 `启动Strudel.command`。
2. 等终端显示服务已就绪，在浏览器打开 <http://127.0.0.1:3009>。
3. 在编辑器中写音乐代码，点击 **play** 开始播放，修改后点击 **update**。
4. 使用期间保持终端窗口打开；在该窗口按 **Ctrl+C** 停止服务。

如果提示“Strudel 已在运行”，直接打开上述地址即可，无需重复启动。此服务只监听本机地址。

## 和官网的区别

这里运行的是 [Strudel 官方源码](https://codeberg.org/uzu/strudel)中的完整编辑器，核心界面、音乐语言和声音引擎与官网相同。安装时使用的 `main` 分支可能比官网已部署版本更新，因此具体功能可能略有差异。

本地运行仍在浏览器中使用。编辑器代码和构建产物位于本目录的 `strudel/` 中；远程音色、采样或外部服务首次使用时仍可能需要联网。浏览器缓存不是永久保存，也不代表已经下载了全部音色。离线使用前应联网播放需要的采样，并保留自己的采样文件。参见[官方离线说明](https://strudel.cc/learn/pwa/)。

作品与设置按浏览器、用户配置和网站地址分别保存。本机 `http://127.0.0.1:3009` 的存储与 `https://strudel.cc` 分开；改用 `localhost`、其他端口或另一个浏览器，也会使用不同的存储。请固定使用上面的地址，并定期导出或另存音乐代码，避免清理浏览器数据后丢失作品。

## 维护

源码目录：`strudel/`。使用项目指定的 **pnpm 10.15.0** 管理依赖；当前机器已有 Node.js 和 pnpm。

如果依赖或构建产物缺失，在终端中运行：

```sh
cd <LEGACY_WORKSPACE>/strudel
<USER_HOME>/.npm-global/bin/pnpm install --frozen-lockfile
<USER_HOME>/.npm-global/bin/pnpm build
```

完成后重新双击启动脚本。首次安装或重新构建可能需要几分钟。
